# Weekly Article Annotations

This folder holds one file per weekly news-article annotation assignment
(see the [assignment steps](#assignment-steps) below).

## Workflow

1. Copy `TEMPLATE.md` to a new file named `YYYY-MM-DD-short-title.md`
   (use the date the article was published).
2. Find a current world/local news article — no celebrity or sports fluff.
3. Read it, then read it again while annotating a printed hard copy.
4. Fill in the template: MLA works-cited entry, summary, annotations,
   your own thoughts/questions (at least 2 questions), and presentation
   notes.
5. Copy the finished write-up into a Google Doc in MLA format and attach
   it to the Schoology assignment. Bring the annotated hard copy to class.
6. Commit the Markdown file here so there's a running record of every
   week's article and questions.

## Assignment Steps

The full assignment rubric (10 pts/week: 5 presentation, 3
summary/questions, 2 annotations) lives in Notion — see the workspace
page **"English 11 — Weekly Article Annotations"** for the tracker and
status of each week.
