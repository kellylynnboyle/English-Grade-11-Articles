# MLA Mini-Lesson Curriculum

One or two lessons get taught each Sunday with the weekly pick. The
routine checks off what's been covered and picks the next unchecked
lesson. Keep lessons short, concrete, and tied to that week's article
when possible.

- [x] 1. Header vs. heading — `Lastname 1` top right of every page vs.
      the four-line name/teacher/class/date block top left, first page only
- [x] 2. Title capitalization — headline-style caps: capitalize first,
      last, and all principal words; lowercase short prepositions,
      articles, and conjunctions (a, an, the, of, to, and)
- [ ] 3. The works-cited entry for an online news article — the
      core pattern: Author. "Article Title." Site Name, Day Mon. Year, URL.
- [ ] 4. Hanging indent — what it is and the Google Docs steps
      (Format → Align & indent → Indentation options → Hanging, 0.5")
- [ ] 5. In-text citations — (Author) for web news, no page numbers;
      skip the parenthetical when the sentence already names the author
- [ ] 6. Italics vs. quotation marks — big containers get italics
      (websites, newspapers, films), pieces inside them get quotes
      (articles, episodes, short works)
- [ ] 7. MLA dates — Day Mon. Year order; which months abbreviate
      (all but May, June, July) and how (Jan., Feb., Aug., Sept. ...)
- [ ] 8. URLs in citations — drop https://, keep www; when an access
      date helps (undated or frequently updated pages)
- [ ] 9. Quoting vs. paraphrasing — when each is stronger, and signal
      phrases ("According to...", "The reporter notes...")
- [ ] 10. No author? No problem — start the entry with the article
      title; shorten it for in-text cites
- [ ] 11. Block quotes — quotes over four lines: indented 0.5", no
      quotation marks, citation after the period
- [ ] 12. Wire stories and two containers — when AP writes it and
      another outlet runs it, which name goes where
- [ ] 13. Ellipses and brackets — trimming a quote honestly with ...
      and clarifying with [brackets] without changing meaning
- [ ] 14. The Works Cited page — centered title (not bold), entries
      alphabetized by whatever comes first, double-spaced throughout
- [ ] 15. Numbers in MLA prose — spell out numbers you can write in
      one or two words; numerals for the rest and for statistics
