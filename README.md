# English-Grade-11-Articles

Tracker for the weekly Grade 11 English news-article annotation
assignment: find a current world/local news article, annotate it, write
an MLA-format summary with personal questions, and present it in class.

- `articles/` — one Markdown file per week's annotation (see
  `articles/README.md` for the workflow and `articles/TEMPLATE.md` for
  the format).
- Status and due dates for each week are tracked in the companion Notion
  page, **"English 11 — Weekly Article Annotations."**
